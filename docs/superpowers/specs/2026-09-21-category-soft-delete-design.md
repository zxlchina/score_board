# 分类软删除设计

日期：2026-09-21

## 目标

分类管理支持删除。删除后分类从管理列表和积分录入选项中消失，且不可从页面恢复。已有积分记录的分数、时间和原分类名称保持不变。

## 方案

在 `categories` 增加可空字段 `deleted_at`。删除只写入时间戳，不删除分类行，不改动 `score_records`。

「可选用」(`is_active`) 仍只表示临时停用，分类继续出现在管理列表。删除与停用互不替代。

## 行为

- 管理列表、录入下拉、分类 API 列表只返回 `deleted_at IS NULL` 的分类。
- 新录入若引用已删除分类则拒绝。
- 积分明细、最近记录、总分/排行继续按现有 `score_records` 计算与展示；分类名仍通过 `category_id` 关联读取（含已删除行）。
- 允许新建与已删分类同名的新分类；旧记录仍挂在原分类行上。
- 删除前确认：删除后从列表消失，已有积分记录会保留原分类名和分数。

## 非目标

- 页面恢复已删除分类
- 硬删除分类行
- 修改或作废存量积分记录
